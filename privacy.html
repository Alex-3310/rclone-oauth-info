rclone-backup 隱私權政策

更新日期：2026-11-18

本政策說明由 Alex-3310 維護的個人備份設定「rclone-backup」，以及此公開說明網站的資料處理方式。本設定僅供擁有者本人備份及還原其資料，未提供公眾備份服務。

存取哪些 Google 使用者資料

rclone 在擁有者授權後，可讀取 Google Drive 的檔名、資料夾結構、大小等中繼資料，以及備份檔案內容，並可上傳、更新及依保留規則處理備份檔案。備份可能包含擁有者選定的個人檔案或開發資料。

若授予完整 Drive 存取範圍，技術權限可涵蓋其他 Drive 檔案；工具設定的備份路徑不是 Google 的資料夾層級權限邊界。

資料用途與處理位置

資料用於建立備份、列出版本、驗證完整性、還原及執行保留政策。rclone 在擁有者的電腦執行；新增的 crypt 備份在本機加密後傳送至其 Google Drive，還原時在本機解密。未採用 crypt 的舊資料不會因新增這份設定或網站而自動變成加密資料。

本備份設定不提供廣告、資料銷售或 AI 模型訓練功能，也沒有第三方備份營運者接收資料。Google 會為儲存、傳輸與 OAuth 授權處理相關資料，適用其 隱私權政策。

憑證與安全

OAuth 存取 Token、Refresh Token 與 crypt 必要參數由擁有者保存在本機設定及受保護的憑證備份中。本公開網站不接收、顯示或保存這些憑證，也不作為 OAuth 回呼端點。網站與其公開原始碼不包含私人備份內容。

保存與刪除

本機與雲端備份依擁有者設定的保留政策保存；舊版、未完成或不受政策管理的備份可能另行保留。符合清理條件的雲端備份依現有設定移至 Drive 垃圾桶，其後的保存與刪除由 Google Drive 規則及擁有者操作決定。

擁有者可停止排程、移除本機憑證，並在 Google 帳戶的第三方連線設定 撤銷授權。撤銷授權不會自動刪除已存在的備份；如需移除資料，須另外處理本機、雲端及其他復原副本。

本說明網站的訪客資料

本網站沒有登入表單、分析程式、追蹤腳本或自行設定的 Cookie。網站由 GitHub Pages 提供託管；GitHub 會為安全目的記錄訪客 IP 位址，適用 GitHub 隱私權聲明。

聯絡與政策更新

問題可透過 本專案的 GitHub Issues 聯絡維護者。請勿在公開留言提供私人資料、Token、密碼、私鑰或備份檔案。資料處理方式如有變更，會更新本頁與日期。
